# Specyfikacje

Jeden dokument na jeden aspekt systemu, numerowany w kolejności powstania; numer mówi, kiedy temat wszedł do kontraktu, nie czym jest. Zasady pisania i cyklu życia tych dokumentów opisuje `SKILL.md` w tym katalogu; Ten indeks jest jedynym dokumentem, który wskazuje na inne.

## Konta i tożsamość

- `01-logowanie-przez-facebooka.md` - model tożsamości zewnętrznej, przepływ w przeglądarce i w powłoce mobilnej, łączenie kont, anonimizacja przy usunięciu, warunki Mety.

## Powłoka mobilna

- `02-powloka-mobilna-tauri.md` - ta sama aplikacja webowa w webview Tauri 2: co działa gdzie, ograniczenia webu w webview, konfiguracja pluginów, Tauri vs React Native.
